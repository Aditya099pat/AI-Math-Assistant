# AI Math Assistant
An AI-powered math assistant built with **Python**, **LangChain**, **OpenRouter** and **SymPy**. that can solve arithmetic, algebra, calculus, trigonometry, and matrix problems using tool-calling.

It supports:

- Basic arithmetic
- Algebraic simplification, expansion, and factorization
- Equation solving
- Differentiation and integration
- Limits
- Trigonometric evaluation and simplification
- Matrix operations such as determinant, inverse, multiplication, and eigenvalues

---

## Features

- Conversational CLI-based math assistant
- Tool-calling architecture using LangChain agents
- Symbolic mathematics powered by SymPy
- OpenRouter integration for model access
- Natural language prompts for mathematical queries
- Covers multiple math domains in a single assistant

---

## Tech Stack

- **Python**
- **LangChain**
- **OpenRouter**
- **SymPy**
- **python-dotenv**
- **uv** for package management
